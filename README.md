## 👨‍💻 Sobre mim

Sou estudante de **Análise e Desenvolvimento de Sistemas no UNIPÊ** e concentro meus projetos em **Python, Django, APIs REST e bancos de dados**. Também desenvolvo interfaces e integrações para entregar aplicações web completas.

Tenho aplicado programação em sistemas web e na **automação de processos e relatórios**. Gosto de entender as regras do problema, organizar o código, documentar decisões e melhorar o que já está em uso.

- **Foco profissional:** desenvolvimento back-end com Python e Django.
- **Atuação prática:** aplicações web, autenticação, dados e automação.
- **Interesses atuais:** arquitetura de software, testes e integração entre front-end e back-end.
