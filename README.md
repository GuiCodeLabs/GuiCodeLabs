## 👨‍💻 Sobre mim

Sou estudante de **Análise e Desenvolvimento de Sistemas no UNIPÊ** e concentro meu desenvolvimento em **Python, Django, APIs REST e bancos de dados**. Também trabalho com tecnologias de front-end para construir aplicações web completas.

Gosto de transformar necessidades reais em software organizado. Tenho aplicado programação tanto em projetos web quanto em **automação de formulários, consolidação de dados e geração de relatórios**. Valorizo regras de negócio claras, documentação, versionamento e código que outras pessoas consigam manter.

### O que você encontra por aqui

- **Back-end:** aplicações web, autenticação, organização de dados e APIs.
- **Full stack:** integração entre interface, lógica de negócio e banco de dados.
- **Automação:** processos que reduzem trabalho manual e tornam informações mais fáceis de acompanhar.
